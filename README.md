## 🛠️ كيف تعدّل الروابط مستقبلًا (بدون أي خبرة تقنية)

1. افتح ملف الصفحة مباشرة من هذا الرابط:
   👉 https://github.com/tbtbshyt-cmyk/bhyr776430697/edit/main/index.html
2. اضغط زر القلم ✏️ (Edit) أعلى يمين الملف.
3. ابحث عن قسم **«منطقة التعديل السهل»** — ستجد قائمة الروابط بهذا الشكل:

```js
const LINKS = [
  { platform: "whatsapp", group: "social", title: "واتساب — قناة التخفيضات",
    sub: "…", url: "https://…", featured: true, tag: "القناة الرسمية" },
  { platform: "facebook", group: "social", title: "فيسبوك", sub: "…", url: "https://…" },
  ...
];
```

4. لتعديل رابط: غيّر نص `url` فقط (بين علامتي التنصيص).
5. لحذف حساب: امسح كامل السطر/الكتلة الخاصة به.
6. لإضافة حساب جديد: انسخ كتلة موجودة وعدّلها، أو أزل التعليق عن أحد الأسطر الجاهزة في أسفل القائمة.
7. اضغط **Commit changes** — يُنشر التعديل تلقائيًا خلال أقل من دقيقة. ✅

### الحقول

| الحقل      | لازم؟ | الوظيفة                                                            |
|------------|-------|--------------------------------------------------------------------|
| `platform` | نعم   | اسم المنصة (يحدّد الأيقونة)                                        |
| `title`    | نعم   | اسم البطاقة                                                        |
| `sub`      | نعم   | الوصف الصغير تحت الاسم                                             |
| `url`      | نعم   | الرابط كما هو                                                      |
| `group`    | لا    | `social` أو `shops` أو `extra` (الافتراضي `social`)                |
| `featured` | لا    | `true` لبطاقة ذهبية بارزة                                          |
| `tag`      | لا    | شارة صغيرة بجانب الاسم (مثل «القناة الرسمية»)                      |

### عناوين المجموعات

عناوين المجموعات في أعلى منطقة التعديل:

```js
const GROUPS = [
  { id: "social", title: "تابعنا على منصاتنا الرسمية" },
  { id: "shops",  title: "فروعنا ومواقعنا" },
  { id: "extra",  title: "روابط إضافية" },
];
```

غيّر `title` فقط لتغيير العنوان الظاهر، ولا تحذف `id`.
