## 🛠️ كيف تعدّل الروابط مستقبلًا (بدون أي خبرة تقنية)

1. افتح ملف الصفحة مباشرة من هذا الرابط:
   👉 https://github.com/tbtbshyt-cmyk/bhyr776430697/blob/arena/01a062b6-bhyr776430697/index.html
2. اضغط زر القلم ✏️ (Edit) أعلى يمين الملف.
3. ابحث عن قسم **«منطقة التعديل السهل»** في أعلى الكود — ستجد قائمة الروابط بهذا الشكل:

```js
const LINKS = [
  { platform: "whatsapp",  title: "واتساب — قناة التخفيضات", sub: "…", url: "https://…" },
  { platform: "facebook",  title: "فيسبوك",                sub: "…", url: "https://…" },
  ...
];
```

4. لتعديل رابط: غيّر نص `url` فقط (بين علامتي التنصيص).
5. لحذف حساب: امسف سطره بالكامل.
6. لإضافة حساب جديد: انسخ سطرًا موجودًا وعدّله.
7. اضغط **Commit changes** — يُنشر التعديل تلقائيًا خلال أقل من دقيقة. ✅
