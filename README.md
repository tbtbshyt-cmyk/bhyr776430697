# 🔗 محلات أبو بشار للملابس والأحذية — صفحة الروابط الرسمية

صفحة واحدة فاخرة (أسود × ذهبي، عربية RTL) تجمع جميع حسابات المحل وروابط التواصل في مكان واحد،
جاهزة للإرسال لأي عميل: يفتحها فيجد كل الحسابات ويضغط على أي منها للانتقال مباشرة.

**الرابط المباشر:** <https://tbtbshyt-cmyk.github.io/bhyr776430697/>

---

## ✨ مميزات الصفحة

- تصميم فاخر Mobile First متجاوب مع الهاتف والكمبيوتر.
- زر بارز لقناة واتساب + بطاقات لكل منصة بأيقونتها واسمها ووصفها.
- زر **مشاركة الصفحة** وزر **نسخ رابط الصفحة**.
- **رمز QR** لرابط الصفحة مع زري «طباعة الرمز» و«تنزيل PNG» (للوضع داخل المحل أو على الفواتير).
- SEO كامل + Open Graph (تظهر معاينة احترافية عند إرسال الرابط في واتساب وفيسبوك).
- سرعة تحميل عالية: لا مكتبات خارجية ثقيلة، الأيقونات SVG مضمّنة.

## 📁 هيكل الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة كاملة (البطاقات بين علامتي `LINKS:BEGIN` و `LINKS:END`) |
| `assets/css/style.css` | التنسيقات (الألوان في متغيرات `:root` أعلى الملف) |
| `assets/js/app.js` | المشاركة / النسخ / QR / الطباعة |
| `assets/js/qrcode.min.js` | مكتبة توليد QR (MIT) |
| `assets/qr.svg` · `assets/og-image.png` · `assets/favicon.svg` · `assets/apple-touch-icon.png` | الهوية والرمز |
| `tools/add_link.py` | إضافة حساب جديد بأمر واحد |
| `tools/make_qr.py` | إعادة توليد رمز QR عند تغيير رابط الصفحة |
| `tools/build.py` | استخراج قائمة الروابط الحالية إلى `tools/links.json` و `tools/links.md` |

## ➕ إضافة حساب جديد لاحقًا (طريقتان)

**1) بأمر واحد (الأسهل):**

```bash
python3 tools/add_link.py --platform tiktok \
  --url "https://www.tiktok.com/@example" \
  --title "تيك توك" \
  --desc "🎵 شاهد أحدث الفيديوهات" \
  --handle "@example"
```

المنصات الجاهزة بأيقوناتها: `whatsapp` `facebook` `instagram` `tiktok` `youtube`
`telegram` `snapchat` `x` `maps` `website` `threads` — وأي اسم آخر يأخذ أيقونة عامة.
خيارات إضافية: `--badge "قناة رسمية"` و `--featured` للإبراز و `--position start` لجعل البطاقة أول القائمة.

**2) يدويًا:** انسخ أي بطاقة `<a class="card ...">` موجودة بين علامتي
`<!-- LINKS:BEGIN -->` و `<!-- LINKS:END -->` في `index.html` وغيّر الرابط والاسم والوصف والأيقونة.

> بعد أي تعديل: ارفع التغييرات (`git add . && git commit -m "تحديث الروابط" && git push`)
> ويُحدَّث الموقع المباشر تلقائيًا خلال دقيقة تقريبًا.

## 🔁 عند تغيير رابط الصفحة نفسه (نطاق جديد مثلًا)

1. حدّث `canonical` وروابط `og:*` في `index.html` وثابت `CANONICAL` في `assets/js/app.js`.
2. نفّذ: `python3 tools/make_qr.py --url "https://new-domain.com/"` لتحديث رمز QR.
